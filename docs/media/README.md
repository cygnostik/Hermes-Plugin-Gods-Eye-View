# Repository media

- `launch-cover.png`: original, AI-assisted satellite concept artwork with deterministic typography and terrain-line illustration. Not a product screenshot, live sensor feed, or classified imagery.
- `catalog-banner.jpg`: 1200 × 600 export of the approved cover for the Hermes catalog.
- `social-preview.jpg`: 1280 × 640 export for GitHub's repository Social preview.
- `catalog.png`: actual Windows capture of GEV embedded in Hermes Desktop, cropped to the plugin and letterboxed. Native imagery attribution is retained. GEV's classification and recording labels are visual styling, not actual classification or recording status.

Cover direction: orbital reconnaissance with early-1990s optical-instrument graphics, ProDyn typography, and a dark Hermes-community editorial treatment. The artwork does not incorporate film frames or official Nous marks. Cover typography uses Oxanium and Departure Mono; only rendered pixels, not font files, are included here.
